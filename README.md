# Финансовый учёт

Быстрый, приватный офлайн-трекер личных финансов. Все данные хранятся локально в браузере
(`localStorage`) и никуда не отправляются. Приложение работает как устанавливаемый PWA: его можно
добавить на главный экран телефона и пользоваться без интернета.

## Возможности

- **Обзор** — сводка за текущий месяц: сколько потрачено сегодня, доходы, расходы, баланс (с
  примерным эквивалентом в рублях), среднее и медиана трат в день, график расходов и разбивка по
  категориям.
- **Операции** — список по дням (заголовок дня прилипает при прокрутке) с поиском по категории или
  сумме, фильтрами и сортировкой. На телефоне операция удаляется свайпом влево, на компьютере —
  кнопкой с подтверждением. После удаления можно нажать «Отменить».
- **Форма операции** — эквивалент в рублях прямо под суммой, быстрые кнопки «Сегодня» / «Вчера»,
  недавние и частые категории первыми, «Повторить сегодня» для повторяющихся трат. Если расход
  довёл бюджет до 80% или 100%, об этом скажет уведомление.
- **Аналитика** — любой период (сегодня, 7 дней, месяц, год, свой диапазон), сравнение с предыдущим
  периодом, самый дорогой и самый дешёвый день, графики.
- **Настройки** — тема (светлая / тёмная / системная), месячные бюджеты (общий и по категориям),
  категории, PNG-отчёт за период, экспорт и импорт JSON, экспорт CSV.
- **Офлайн** — после первой загрузки все разделы открываются без сети.

## Запуск проекта

```bash
npm install
npm run dev       # сервер разработки: http://localhost:5173/finance-tracker/
npm run build     # проверка типов + production-сборка в dist/
npm run preview   # production-сборка локально: http://localhost:4173/finance-tracker/
npm test          # тесты (Vitest)
npm run lint      # линтер (oxlint)
```

В режиме `npm run dev` service worker не работает, поэтому офлайн-режим и установку PWA проверяйте
через `npm run build && npm run preview` (в Chrome DevTools → Application → Service Workers).

Чтобы открыть preview с телефона в той же Wi-Fi сети: `npm run preview -- --host`.

## Деплой и ветки

- **Production — Vercel, только из ветки `main`.** На Vercel приложение собирается с базовым путём `/`,
  локально и в остальных окружениях — с `/finance-tracker/` (см. `vite.config.ts`).
- Новые изменения делаются в ветках `feature/*` и попадают в `main` только после проверки.
- **GitHub Actions:**
  - `Feature CI` — на каждый push в `feature/**` и на pull request в `main`: `npm ci`, lint, тесты, сборка;
  - `Build and Deploy` — на push и pull request в `main`: те же проверки и сборка для GitHub Pages.

Маршрутизация — `HashRouter` (адреса вида `/#/transactions`), поэтому дополнительная настройка
SPA-маршрутов на хостинге не нужна.

## Архитектура

- **`src/lib/storage.ts`** — единственный модуль, который работает с `localStorage`. Остальная
  часть приложения использует его через хуки, поэтому слой хранения можно заменить без переписывания UI.
- **`src/lib/calculations.ts`** — чистые функции финансовых расчётов: доходы, расходы, баланс,
  среднее и медиана, разбивка по категориям, прогресс бюджетов и т. д.
- **`src/lib/date-utils.ts`** — календарные даты без часовых поясов. Даты операций хранятся как строки
  `yyyy-MM-dd`.
- **`src/lib/exchangeRate.ts`** — курс VND → RUB только для отображения (кеш на 12 часов,
  без сети — последний сохранённый или примерный курс).
- **`src/hooks/`** — хуки для областей данных (`useTransactions`, `useCategories`, `useBudgets`,
  `useSettings`) и вспомогательные хуки.
- **`src/context/AppDataContext.tsx`** — общее состояние приложения, чтобы все страницы работали
  с одними и теми же данными.
- **`src/i18n/`** — все строки интерфейса (сейчас русский язык).
- **`src/components/`** — компоненты по функциональности: `transactions/`, `categories/`, `budgets/`,
  `dashboard/`, `analytics/`, `period/` (выбор периода), `settings/`, `layout/` и базовые компоненты
  в `ui/`.
- **Контексты** отдают стабильные значения: открытие формы операции или показ toast не
  перерисовывают текущую страницу целиком.

### Загрузка и офлайн

- **Первый экран грузится быстро.** Обзор входит в основной бандл. Остальные разделы и графики
  (Recharts) вынесены в отдельные чанки и подгружаются по мере необходимости, а после первой
  отрисовки — заранее, в фоне (`src/lazyPages.ts`, `src/lib/lazyWithPreload.tsx`).
- **Без пустых экранов.** Пока раздел загружается, навигация остаётся на месте и показывается
  заглушка. Если раздел не удалось загрузить без сети, показывается понятное сообщение с кнопкой
  «Повторить» (`ChunkErrorBoundary`); при появлении сети повтор происходит автоматически.
- **Экран запуска** встроен прямо в `index.html` и появляется в первом же кадре, ещё до загрузки
  JS и CSS. Тема определяется до отрисовки, поэтому в тёмной теме нет белой вспышки.
- **PWA** — `vite-plugin-pwa` (Workbox) кеширует все файлы сборки; установленное приложение
  открывается и работает без сети.

## Основные решения

- **Валюта:** все суммы хранятся и считаются только в VND (₫), целыми числами, не больше
  999 999 999 999 ₫. Рубли показываются только как примерный эквивалент в карточках сводки и нигде
  не сохраняются.
- **Расчёты за период** делаются за один проход (`summarize` в `src/lib/calculations.ts`).
  Среднее и медиана в день считаются только по уже прошедшим дням: 24 сентября «Этот месяц» делится
  на 24 дня, а не на 30. Сравнение с прошлым периодом тоже берёт равный отрезок: 1–24 сентября
  против 1–24 августа.
- **Хранение:** данные находятся только в браузере пользователя. Бэкенда, аккаунтов и синхронизации нет.
- **Резервная копия:** данные можно экспортировать в JSON и восстановить из резервной копии. Файл
  полностью проверяется до записи, а запись идёт по принципу «всё или ничего»: если что-то не
  получилось (например, не хватило места), текущие данные остаются нетронутыми.
- **Экспорт:** операции выгружаются в CSV (разделитель `;` и UTF-8 с BOM — Excel с русскими
  настройками сразу раскладывает столбцы), отчёт за выбранный период — в PNG (через `html-to-image`,
  библиотека загружается только при генерации отчёта). Имя отчёта говорит о периоде:
  `report-2026-09.png`. На телефонах файлы сохраняются через системное меню «Поделиться» (если
  браузер умеет делиться файлами), на компьютере — обычной загрузкой.
- **Смена дня:** если приложение открыто через полночь, «Сегодня» и «Этот месяц» переключаются сами
  (и при возвращении в приложение).
- **Идентификаторы** создаются и без `crypto.randomUUID`, поэтому приложение работает и по обычному
  http в локальной сети (`npm run preview -- --host`).
- **Графики:** Recharts.
- **Бюджеты:** всегда месячные, общий или для конкретной категории.
- **Удаление категории:** если категория используется, её операции сначала нужно переназначить на
  другую активную категорию того же типа. Операции автоматически не удаляются, а бюджет этой
  категории удаляется вместе с ней.
- **Удаление операции:** свайп влево на телефоне (удаляет после порога, с отменой через toast),
  кнопка с подтверждением на компьютере.
- **Мобильный ввод:** форма операции подтверждается клавишей Done/Enter на экранной клавиатуре.
- **Анимации** короткие и спокойные, учитывают системную настройку «Уменьшить движение».

## Тестирование

`npm test` запускает тесты Vitest (jsdom). Они покрывают:

- финансовые расчёты: доходы, расходы, баланс, среднее и медиана (только по прошедшим дням),
  категории, самый дорогой и дешёвый день, сравнение с прошлым периодом, пороги бюджетов;
- резервные копии: экспорт и повторный импорт, отклонение повреждённых файлов, запись «всё или
  ничего», удаление бюджета вместе с категорией, лимит суммы;
- подготовку данных графика расходов (выбросы, пустые и нулевые данные);
- курс рубля: форматирование, кеш, работу без сети, отсутствие параллельных запросов;
- список операций: свайп (следование за пальцем, порог, сопротивление, возврат, отсутствие случайного
  открытия), удаление на компьютере с подтверждением, удаление именно нужной операции;
- загрузку разделов: заглушку при загрузке, сообщение при ошибке, повторную попытку;
- экспорт: CSV для Excel, имена файлов отчёта, «Поделиться» на телефоне и загрузку на компьютере;
- фильтр операций по архивной или удалённой категории, смену дня при открытом приложении;
- форму операции (рубли, быстрые даты, «Повторить сегодня»), порядок категорий, поиск по сумме,
  предупреждения о бюджете;
- экран запуска, сброс прокрутки при смене вкладки, отсутствие выбора периода на Обзоре.

Перед отправкой изменений запускайте:

```bash
npm run lint
npm test
npm run build
```
